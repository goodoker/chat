# Концепция проекта

Разработан пакет приложений для организации консольного группового чата. Система состоит из серверной и клиентской части, обеспечивающей обмен текстовыми сообщениями между пользователями через сеть.

## Ключевые характеристики

* **Логирование:** Все входящие и исходящие сообщения фиксируются в файле `file.log` как на стороне сервера, так и на каждом клиенте. Файл постоянно дополняется.
* **Завершение работы:** Выход из чата осуществляется путем ввода команды `exit`.
* **Конфигурация:** Параметры подключения (адрес, порт) хранятся в общем файле `settings.txt`.

## Серверное приложение

* Функционирует как автономный фоновый процесс.
* Ожидает и управляет подключениями множества клиентов.
* Ретранслирует полученные сообщения всем подключенным клиентам.
* Ведет детальный журнал сообщений с метками времени и идентификаторами отправителей.

## Клиентское приложение

* Запускает два независимых потока: один для отправки сообщений, другой — для их приема.
* Предоставляет пользователю возможность указать свое имя в чате.
* Обеспечивает интерфейс для ввода текста и просмотра сообщений от других участников в реальном времени.

## Реализация

Проект включает работающую систему с одним сервером и двумя клиентами, способными общаться между собой.
